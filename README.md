# 斗罗大陆人生模拟器

基于《斗罗大陆》第一部世界观的沉浸式开放世界文字RPG，纯前端HTML游戏。

## ✦ 特色

- **高自由度**：你可以是任何人，做任何选择，走任何路线
- **完整角色创建**：出身、家庭、武魂、天赋、性格——每一步都由你决定
- **修炼体系**：魂力等级、魂环获取、魂技领悟，严格遵循原著设定
- **战斗系统**：元素克制、魂技消耗、战术选择
- **开放世界**：诺丁城、星斗大森林、武魂城、天斗城等区域自由探索
- **NPC互动**：唐三、小舞、比比东等核心角色可结识并发展关系
- **存档系统**：5个存档槽位，支持随时读档

## ✦ 快速开始

直接在浏览器中打开 `index.html` 即可开始游戏。

## ✦ 玩法

1. **创建角色**：选择出身、天赋、武魂，打造独一无二的角色
2. **探索世界**：在不同区域间旅行，触发随机事件
3. **修炼变强**：冥想修炼提升魂力，猎杀魂兽获取魂环
4. **结识人物**：与原著角色互动，好感度影响关系走向
5. **自由发展**：没有固定主线——你想做什么，什么就是主线

## ✦ 技术栈

- 纯HTML/CSS/JavaScript
- 无需服务器，无需安装
- localStorage本地存档

## ✦ 世界观

严格遵循《斗罗大陆》第一部（斗罗一）设定：
- 魂力体系：1-99级 + 神级
- 魂环年限上限：第一环≤423年 ... 第九环≤100000年
- 武魂分类：兽武魂、器武魂、植物武魂、食物系、辅助系、变异武魂
- 势力格局：武魂殿、上三宗、两大帝国
